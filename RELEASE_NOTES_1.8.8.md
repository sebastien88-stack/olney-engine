# Olney Engine 1.8.8 — préparation locale

- Icône Windows avec canal alpha et masque de transparence explicite.
- Nouveau fichier d’icône référencé directement par les raccourcis pour éviter
  la réutilisation de l’ancienne référence mise en cache.
- Roue dentée de configuration : connexion/clés API Emmett et mises à jour.
- Suppression du bouton Mise à jour séparé.

L’installation locale doit être mise à jour avec ce nouvel installateur.
Les raccourcis déjà épinglés à la barre des tâches peuvent devoir être désépinglés
puis réépinglés si Windows conserve leur ancienne icône.
Cette préparation ne publie pas de nouvelle Release GitHub.
