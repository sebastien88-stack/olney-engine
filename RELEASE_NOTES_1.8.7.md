# Olney Engine 1.8.7 — préparation locale

- Icône pique sur fond transparent, obtenue à partir des traits du logo original.
- Point retiré après « Biblaridion » dans le sous-titre de l’application.
- Bouton Mise à jour : vérification manuelle des Releases GitHub stables.
- Proposition de téléchargement de l’installateur officiel uniquement.

Le téléchargement s’ouvre dans le navigateur après accord. L’utilisateur ferme
Olney puis lance l’installateur pour mettre à jour sa copie Windows. Il ne
s’agit pas d’une installation automatique silencieuse. Une modification du code
sur GitHub ne déclenche rien : il faut une Release stable avec son installateur.

Les données personnelles restent dans leur base locale hors de l’installation.
Cette préparation locale ne crée pas de Release publique. Les vérifications de
droits de LICENSING.md restent nécessaires avant toute prochaine distribution.
