# Olney Engine 1.8.5

Cette version synchronise l’application, le moteur et la distribution Windows
autour de la nouvelle identité visuelle d’Olney Engine.

## Nouveautés

- logo pique officiel sur l’exécutable, la fenêtre et les raccourcis Windows ;
- étoile historique intégrée à l’assistant d’installation ;
- palette parchemin pour le mode clair et l’installateur ;
- raccourci Bureau proposé par défaut ;
- dépôt GitHub préparé sans profils, événements, relations, conversations,
  bases personnelles ou clés API ;
- installateur autonome : Python n’est pas requis pour l’utilisateur final.

## Fichiers proposés

- `Olney_Engine_Setup_1.8.5.exe` : installation Windows recommandée ;
- archive portable facultative, à extraire avant de lancer `Olney Engine.exe`.

## Remarque Windows

L’application n’étant pas encore signée avec un certificat de signature de
code, Microsoft SmartScreen peut afficher un avertissement au premier lancement.
